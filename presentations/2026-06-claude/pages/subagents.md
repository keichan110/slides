# Subagents

:: content ::

- Claude が別の Claude インスタンスにタスクを依頼して並列処理する仕組み
- 調査・検索などをサブに任せることでメインの会話が圧迫されない
- タスクの種類に応じて専門化されたエージェントを指定できる

| メリット | 内容 |
|---|---|
| 速さ | 独立したタスクを並列実行してトータル時間を短縮 |
| 集中 | 調査・検索はサブに任せてメインは実装に専念 |
| 専門化 | コード探索・設計・レビューなどを専門エージェントに委任 |

# Subagents

:: content ::

| ユースケース | 説明 |
|---|---|
| 並列コード探索 | 複数キーワードを同時に検索してメインの応答速度を上げる |
| 独立したレビュー | セキュリティ・パフォーマンス・可読性を別々のエージェントが担当 |
| 大規模リファクタリング | モジュール単位に分担して並列処理 |
| 調査と実装の分離 | 調査エージェントが情報収集、メインが実装に専念 |

<!--
⏱ 約1分

「調査と実装の分離」が特に実感しやすいユースケースです。調査のために何十ものファイルを開いていくと、メインの会話が脱線しがちですが、Subagentsに任せることでメインは実装だけに集中できます。大規模リファクタリングでもモジュール単位に分担できるため、一度に扱う変更量を抑えられます。
