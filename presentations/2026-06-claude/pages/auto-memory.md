# Auto Memory

:: content ::

- 会話の中で Claude が気づいたことを自動でメモし、次のセッションに持ち越す仕組み
- 人間が何も指定しなくても、会話を重ねるほど「わかってくれる」ようになる

## CLAUDE.md との違い

| | CLAUDE.md | Auto Memory |
|---|---|---|
| 誰が書く | 人間 | Claude |
| 何を書く | ルール・規約・コンテキスト | 学習・気づき・ユーザーの好み |
| いつ書く | 明示的に編集したとき | 会話の中で自動的に |

> `/memory` コマンドで内容を確認・編集できる
