# Plugins

---

# Plugins とは

Skills・Hooks・MCP サーバーなど複数のコンポーネントを**ひとつのパッケージ**にまとめて配布・共有できる仕組み

- 「誰かが作った便利な機能セット」をそのまま使える — 自分で一から作る必要がない
- マーケットプレイスで公開されているプラグインをインストールするだけで使えるようになる
- チームやコミュニティで作ったカスタマイズを配布するためにも使える

---

# プラグインに含められるもの

| コンポーネント | 役割 |
|---|---|
| Skills | `/コマンド名` で呼び出せるカスタムワークフロー |
| Agents | 特定タスク専用のサブエージェント |
| Hooks | 操作の前後に自動実行される処理 |
| MCP サーバー | 外部ツール・サービスとの連携 |
| LSP サーバー | リアルタイムのコード補完・診断 |

---

# インストールと共有

マーケットプレイスで公開されているプラグインを探して、ワンステップでインストールできる

- インストールするだけで Skills・Hooks・MCP サーバーがまとめて有効になる
- プロジェクトにプラグインを含めておけばチーム全員が同じ環境をすぐ使える
- 自作のプラグインをマーケットプレイスに公開してコミュニティと共有することもできる
