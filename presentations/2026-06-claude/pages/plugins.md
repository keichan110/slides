# Plugins

:: content ::

- Skills・Hooks・MCP サーバーをひとつのパッケージにまとめて配布・共有できる仕組み
- インストールするだけで関連機能がまとめて有効になる
- チームのカスタマイズをパッケージ化して全員に一括配布できる

## 公式プラグイン（anthropics/skills）

| プラグイン | できること |
|---|---|
| PowerPoint / Excel | プレゼン・スプレッドシートをワンコマンドで作成 |
| Brand Guidelines | ブランドのトーン・スタイルに沿った出力に統一 |
| Frontend Design | フロントエンドのデザイン品質を自動改善 |
| Claude API Helper | Anthropic API の最新パターンでコードを生成 |
| MCP Builder | MCP サーバーの雛形を自動構築 |
