# Skills

:: content ::

- 定型ワークフローを一度作れば、何度でも `/コマンド名` で呼び出せる仕組み
- Claude.ai・Claude Code・API のすべてで動作する
- 「毎回同じことを説明する」手間から解放される

| スキルの種類 | 例 |
|---|---|
| Built-in | Excel・PowerPoint 作成、データ分析、ファイル変換 |
| 組織・チーム | ブランドガイドライン適用、業界別ワークフロー |
| 個人 | 自分のメモフォーマット、開発ワークフロー |

<!--
⏱ 約1分

Skillsは「自分専用のスラッシュコマンドを作れる」機能です。毎回同じプロンプトを書かずに済むだけでなく、一度作ったスキルはチームや組織全体で共有できるので、ノウハウの資産化にもなります。Built-inで最初から使えるものもありますが、真価は自分で定義できる点にあります。

→ 次：実際にどんな場面で使えるか、具体例を見ていきます

# Skills

自分で作れるスキルの例

| ユースケース | 概要 |
|---|---|
| PR レビュー | コードの差分を取得してリスク・変更点を自動要約 |
| 議事録整形 | 箇条書きメモを構造化された議事録に変換 |
| 文体統一 | 社内ガイドラインに沿った文章に書き直す |
| 週次レポート | git log やタスク一覧から週次報告書を生成 |
| データ変換 | CSV を指定フォーマットの JSON に変換 |
| ブログ下書き | アイデアの箇条書きから記事の下書きを生成 |

<!--
⏱ 約2分

これらはあくまで例ですが、共通しているのは「毎回同じ手順を踏む作業」である点です。PRレビューや議事録整形は、手順を一度スキルに落とし込めば、あとは`/コマンド名`一発で動きます。特にチームで使うと、レビューの観点や文体が統一されるメリットもあります。
